# TFM – Análisis comparativo de plataformas de Business Intelligence

Trabajo Fin de Máster – Máster Universitario en Análisis y Visualización de Datos Masivos (UNIR)
Autor: Diego Encalada García

Comparativa empírica de Power BI, Tableau y Looker Studio (Data Studio) construyendo el mismo dashboard sobre el conjunto de datos Online Retail II.

## Contenido (carpeta `tfm-comparativa-bi/`)
- `notebook/`: análisis exploratorio y limpieza del conjunto de datos (Python, pandas).
- `datos/`: bitácora de limpieza, registros excluidos y registros de rendimiento de Tableau.
- `figuras/`: figuras del análisis y capturas de cada plataforma.
- `dashboards/`: archivos de Power BI (.pbix) y Tableau (.twbx).
- Dashboard de Looker Studio: https://datastudio.google.com/reporting/c8c1ae12-259e-49b6-acc0-39de0d0edbb4

## Datos
Online Retail II (Chen, 2012), UCI Machine Learning Repository, licencia CC BY 4.0.
https://doi.org/10.24432/C5CG6D
El archivo limpio se genera ejecutando el notebook sobre el archivo original.
